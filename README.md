# ActForGoa field guide

A public-site archive and searchable redesign of [ActForGoa](https://actforgoa.org/), prepared for client review. The existing live website has not been replaced.

[Open the client-review site](https://actforgoa-field-guide.vercel.app/) · [Private GitHub repository](https://github.com/ZakKrevitt/ActForGoa)

## Run locally

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:4173. Build with `npm run build`; test with `npm test`. Node 22.12+ or 24 is recommended. The dependency lockfile and npm install-script allowlist are committed.

## What works

- Search across 600 imported entries plus five authored practical guides: reporting, building, farming, animal welfare and environmental protection.
- Practical guides include official citations, 17 editable template downloads, section navigation and a visible verification register. They remain clearly labelled drafts pending legal and live-service review.
- Hybrid retrieval: weighted keyword search, explicit intent expansion, and local MiniLM semantic vectors. Queries run in a browser worker and are not sent to an AI provider. Keyword results appear immediately while the local model loads.
- Searchable directory, topic filters, grouped search answers, list/grid views, reading library, long-form records, original document links, email links, and shareable URLs. Public presentation links to official contact directories while keeping source-listed phone data in the underlying research records.
- About, participation, and contact routes. Contact/correction forms prepare a reviewable email; they do not send or store submissions.
- Original mission, source links, publication dates, contact verification notices, and original site photography.
- Phone and desktop layouts, keyboard focus, reduced-motion support, empty states, and keyword fallback if the semantic model is unavailable.

| `archive/site-responses.tar.gz` | Portable raw HTML/API/sitemap responses and append-only fetch evidence |

Raw archive files retain the original site's wording and code, including failures, placeholder pages, obsolete material, and original styling. These files are evidence, not executable application code. Do not deploy the raw archive as the public application.

## Rebuild the data

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm run crawl
.venv/bin/python scripts/recover_directory.py
.venv/bin/python scripts/crawl_library.py
npm run extract
npm run audit:links
.venv/bin/python scripts/inventory.py
npm run index:semantic
npm run build
```

The archive is resumable. Its manifest reuses prior successful responses, so begin a separate archive for a truly fresh snapshot. See the coverage report for robots boundaries, server failures, API count discrepancies, and unverified contacts.

After editing `corpus/guides/`, run `python3 scripts/publish_guides.py`, then `npm test` and `npm run build`. Commit the generated content with its source. The Vercel build uses the generated files and does not upload or depend on the local raw research corpus. The five new guides participate in keyword search; the semantic index remains the original 600-entry archive.

## Deployment

Vercel serves the Vite `dist/` directory. `vercel.json` supplies route fallbacks and keeps the preview out of search engines. Deployment is a client-review preview; a production cutover requires an explicit decision. The model and runtime are lazily loaded, with a roughly 50 MB uncompressed first-use semantic payload; keyword search remains usable during loading or failure.

The separate Vercel project is `actforgoa-field-guide`. Its public review URL uses that project's production alias; it has no connection to the `actforgoa.org` domain or original hosting. `.vercelignore` excludes the raw archive, Python tooling, development notes and unrelated research, while retaining `public/data/`. Deploy with `vercel deploy --yes --prod --project actforgoa-field-guide` to update this review URL.

## Before a production launch

Verify and assign owners to contact records, especially the snake-rescue list from 2018. Review historical legal/medical information, automatic topic classification, stale campaigns, and imported wording. Decide editorial roles, multilingual scope, update cadence, a real mail/submission service, and hosting/domain ownership. Complete production accessibility and load testing. These are recorded follow-ups, not claims that this preview is a verified emergency directory.
