# Google services in the satellite workspace

Earth Engine is an explicit alternative imagery provider. Set `SATELLITE_IMAGERY_PROVIDER=earth-engine`, `EARTH_ENGINE_PROJECT`, and the server-only `EARTH_ENGINE_CREDENTIALS_JSON` authorized-user credential. The existing OAuth grant is limited to `earthengine.readonly`; this integration performs no exports or asset writes. Personal OAuth can be revoked or expire and then needs reconnecting. A separately provisioned service identity is a future operational improvement, not configured by this change.

Acquisitions come from `COPERNICUS/S2_SR_HARMONIZED`. Scene identifiers have an `ee-` prefix so retained CDSE rasters cannot collide with Earth Engine observations. Each request retrieves one exact scene with verified acquisition time, six scaled reflectance bands, native categorical SCL and a validity mask, on the existing snapped UTM 10 m grid. SWIR/SCL remain native 20 m measurements. Existing area limits, actor-private cache, cloud buffering, numerical comparisons and uncertainty thresholds remain in force. CDSE remains available by explicitly selecting `cdse`; no silent provider fallback occurs.

`GOOGLE_MAPS_API_KEY` belongs only on the Python API service. The authenticated, CSRF-protected `/environment` action fetches current weather and air quality at the selected area's centre, at most 50 requests (100 provider calls) per UTC day across the service. Each provider response is time- and size-bounded; one provider can fail independently. Responses are not retained with investigations. The frontend displays timestamps and Google Maps attribution and clears readings when the area/account changes. Google directions use a Maps URL. The current OSM/Photon map remains unchanged; the server key is never embedded in a browser bundle. Browser Maps JavaScript would require its own website-restricted key.

OpenAI Decisions is an independent, existing optional classifier. It runs only when explicitly configured and there is sufficient common clear coverage. No OpenAI credential was present during this integration, and no model request was made. Numerical imagery evidence remains available. Combining Earth Engine pixels and Decisions does not establish model accuracy, causal conclusions, or individual-tree loss.

Validation: 140 Python satellite tests, 221 Node tests, production TypeScript/Vite build; live local Earth Engine catalogue and aligned GeoTIFF retrieval; real Google Weather/Air Quality UI results. Hosted deployment/acceptance is recorded separately in the implementation ledger and release report.

References: [Earth Engine download API](https://developers.google.com/earth-engine/apidocs/ee-image-getdownloadurl), [Sentinel-2 collection](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED), [Google Weather attribution](https://developers.google.com/maps/documentation/weather/policies), [Google Air Quality attribution](https://developers.google.com/maps/documentation/air-quality/policies), [OpenAI Decisions](https://developers.openai.com/api/docs/guides/decisions).
