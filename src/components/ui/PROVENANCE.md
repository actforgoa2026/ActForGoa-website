# shadcn/ui controls

Retrieved from official shadcn/ui sources on 23 October 2026:

- Switch: https://raw.githubusercontent.com/shadcn-ui/ui/main/apps/v4/registry/new-york-v4/ui/switch.tsx
- Checkbox: https://ui.shadcn.com/r/styles/new-york/checkbox.json
- License: https://github.com/shadcn-ui/ui/blob/main/LICENSE.md (MIT).

The original Radix Root, Thumb, Indicator, props and ref composition are retained. The Switch imports the individual Radix package instead of the aggregate package. Tailwind utility classes are translated to controls.css using the existing ActForGoa palette, upright type and focus treatment. Targets are enlarged; reduced motion is supported. Arc Input, Textarea, Button and SegmentedControl supply the remaining editor controls; their sources are recorded in ../arc/PROVENANCE.md.
