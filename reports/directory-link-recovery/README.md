# Directory link recovery, 27 October 2026

Rechecked 48 previously unverified unique addresses covering 116 records using HTTPS requests with normal certificate verification and a 15-second timeout, followed by investigation of candidate replacements. `results.json` records the original check and the selected destination and status for each record; `candidate-checks.json` records the initial candidate checks. Additional checks returned HTTP 200 for `https://goasacs.goa.gov.in/` and the Goa government profiles for the Indian Red Cross Goa branch, Women and Child Development, and Institute Menezes Braganza.

The update provides 11 organisation websites and 83 related reference pages. The references include the election commission homepage for 50 records whose historical election page returned 404; it is a general reference, not evidence of an individual election result. Similarly, the Goa IDC profile is a general corporate reference for the estate listings. Twenty records still have unverified links; one site was intermittent, and one previously unverified site responded. An HTTP response only establishes access at the time of checking, not ownership, current operations or future availability. The original source values remain in the catalogue and MCP output.
