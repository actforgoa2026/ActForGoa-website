# Directory destination and duplicate audit, 27 October 2026

The 3,267-record CRM snapshot contained 426 distinct syntactically valid website destinations after the preceding correction. Each was requested using Python's standard HTTPS client, following redirects with certificate verification, a 12-second timeout and a maximum of two concurrent requests per host. Responses and error classifications are in `src/content/directory-website-checks.json`; the site exposes a dated caution for inconclusive responses, and the MCP reports the check status. 317 returned HTTP 200 and 38 HTTP 206; four returned 404, two 500, one 526, and 64 produced connection, DNS, timeout or TLS errors. A response code does not prove that the page is accurate, current, usable or belongs to the named entity. Failures describe this check only and do not establish permanent unavailability. The user-facing source data remains unchanged. The unparseable email-as-URL identified in the preceding audit remains suppressed.

Certificate hostname mismatches were retested without `www`; 19 alternatives responded with a valid TLS connection and HTTP 200. The domain and path remain the same apart from the prefix. Four different domain replacements use official institutional sources: Goa's department page for science and waste management, the Goa RERA about page, and the Goa government useful-links page for water resources and urban development. Each replacement responded HTTP 200 on the check date. Their source is returned by MCP and linked from the website record. The outdated accounts domain was not automatically replaced because the official alternative failed the connection check from this environment.

The remaining 147 exact-normalized-name groups from the prior audit were reviewed using recorded roles, organisations, jurisdictions, phone numbers and source URLs. Thirteen further pairs represent the same institution or named appointment and are grouped while retaining alternate listings, source links and distinct local notes. Where a name is shared across different jobs or geographic assignments, or the identity is uncertain, records remain separate. This review does not rule out spelling variants, unnamed duplicates, changed appointments or coincidental identity matches. No person or service availability was independently established.
